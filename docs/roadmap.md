# Roadmap

## MVP (0.1)
Local doctor, text inspect/scan, privacy-first reports, Docker status, deterministic analysis, optional OCR architecture.

## v0.2
Enable and harden opt-in Tesseract screenshot redaction; structured stack-frame summaries; detector corpus expansion.

## v0.3
Explicit-scope `record` sessions and reviewed GitHub issue drafts; application-specific diagnostic collectors.

## Future
Optional local AI/Ollama analysis, sanitized-only MCP server, IDE/VS Code integrations, and explicit shell-history capture with privacy filters. No feature will silently record or publish user data.
